# The Zero Slot — Co-creation Guide

> A LitRPG novel whose **numbers are machine-verified**. Level up, allocate stats,
> clear rifts — and the stat ledger is checked by a machine gate on every chapter.
> Broke the ledger (spent points you don't have)? The chapter is rejected.

## How to participate (5 levels, easy → deep)

### ① Vote (zero effort, weekly)
Discussions: each week we vote on where Kael goes next / which skill to take.
React with 👍 — the top pick goes into the next chapter.

### ② Nominate (one sentence)
Open an Issue with the `Nominate` template:
"I want to see a rift under the old cathedral" / "a sky rift over the harbor".

### ③ Create: submit skills / equipment / rift designs (deep)
Open the `Skill or Item` / `Rift` templates and submit a full design
(name + effect + numbers). If merged into spec, Kael may acquire it next chapter —
your GitHub handle is credited in the chapter:
「Designer: @yourhandle」.

Requirements:
- Skills: name, tier, effect, stat cost — numbers must be consistent with the ledger
- Rifts: name, depth, monster(s), loot table, mechanic
- Check spec/ first to avoid conflicts with established canon

### ④ Bug-hunt: catch ledger breaks (this repo's specialty)
The stat ledger is machine-checked per chapter. If you find a chapter where
numbers don't add up (level, stats, stat_points), open an Issue with the
`Ledger Bug` template. First valid report goes to the top of the leaderboard.
This is a novel you can audit like open source.

### ⑤ Side stories (advanced)
Write slice-of-life side stories between Kael's runs. If canon-consistent
(no rule/state violations), they get merged with your name in provenance.

## Credit loop
- Every merged contribution is recorded in provenance (`by` = your GitHub id)
- README leaderboard updates monthly
- Designs that enter chapters are permanently credited

## Rules
- Prose is generated by AI through the Origin IR gate; world & rules are human-curated
- Ledger rule: str+agi+int+vit+wis+stat_points = 25 + (level-1)*5
- Read CONTRIBUTING.md fully + spec/ before submitting

## Layout
```
spec/           world spec (canon/ characters·items·locations / narrative/ hooks / tasks/ zones)
chapters/       prose (ch01.txt, ch02.txt …)
state/          world state stream (every commit's semantic transaction, public)
```
